## ReactJs-NodeJs-Postgres-App

Lastest version of app: 18/11/2026 13h22

**auth argon2Async** uniquement disponible à partir de la version **node: v24.7.0** 

Frontend: "React", redux, "ReactHookForms", 'Formiz", "Formik", "Tanstask React Query"
Backend: "node.js", "express.js", connecté à une base de données relationnelle, "Postgres".

Utilisation de **react-persist** pour sauvegarder les utilisateurs connectés. 

### Docker

Initialisation de Postgres et importation de la base donnnées.

```bash
docker compose up -d
```
